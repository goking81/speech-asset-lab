# F3-03｜R5 Coach 建议与计划降级

## 目标

在不改变本地资格、阶段、拼贴门禁或正式任务顺序的前提下，让 R5 对已经生成的本地日计划提供可回退的解释性 Coach 草稿。

## 必做

1. R5 只接收当前 `DailyPlan` 的本地任务快照；不得增加资产、问题或任务。
2. R5 输出仅作为 `AiTask`/`AiTaskAttempt` 草稿保存，包含总体建议和对现有任务的解释；不得更新 `DailyPlan` 或 `TrainingTask`。
3. Provider 未配置、失败、超时或草稿结构无效时，返回明确状态并继续展示 F3-01 本地计划。
4. 今日训练页明确区分“本地资格理由”和“AI Coach 草稿”，并支持用户显式请求 R5。

## 禁止

- 不得让 R5 改变阶段、资产资格、拼贴解锁、任务类型、正式任务顺序或状态；
- 不得在没有本地任务时伪造 Coach 建议；
- 不得自动触发网络调用或把 R5 草稿写入正式计划字段。

## 验收

- R5 成功、未配置、Provider 失败和非法草稿四种状态均不会改变本地日计划；
- 任何 R5 task note 只能引用当前计划中存在的任务 ID；
- 首页在 R5 未请求或失败时仍可正常显示本地任务和本地原因；
- AI 建议在 UI 中始终标为草稿。
