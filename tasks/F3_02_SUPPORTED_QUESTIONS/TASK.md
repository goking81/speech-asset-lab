# F3-02｜R4 受支撑问题与 P07 准备

## 目标

创建可追溯到已掌握个人资产、已确认个人事实或题面上下文的问题计划；P07 必须展示 3—4 个中文回答节点，并默认折叠英文表达。

## 必做

1. 只允许已确认、已激活且处于可调用阶段的个人资产参与问题计划。
2. 问题计划冻结主资产及至多一项补充资产版本；每个回答义务都必须保存支撑映射。
3. 用户真实问题先由本地规则校验再保存；R4 只能输出待确认草稿，且仅使用当前可调用资产与已确认个人事实。
4. P06 展示真实可调用资产和问题计划；P07 展示问题、3—4 个中文骨架节点及默认折叠的英文表达。

## 禁止

- 不得在没有可调用资产时生成或发布问题；
- 不得让 AI 自动创建正式 `Question` 或 `QuestionPlan`；
- 不得使用未确认个人事实、来源资产或 S0—S1 资产作为问题支撑；
- 不得把展开的准备材料记录为正式提示等级。

## 验收

- 无支撑、资产不属于本地用户、资产非当前可调用状态或节点不足时，本地服务拒绝创建并说明原因；
- 每个 `QuestionObligation` 可定位到个人资产节点、已确认个人事实或题面上下文；
- R4 失败时不创建随机问题，用户已输入的问题不丢失；
- P07 的英文表达默认折叠，且不创建训练会话。
