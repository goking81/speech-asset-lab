# F4-02｜P08 两次回答、提示与恢复

## 目标

从已验证的受支撑问题准备建立可恢复的本地回答会话，完成第一次回答、直接进入第二次回答以及两次独立文字记录的主链路。

## 必做

1. 建立或恢复 `TrainingSession`，绑定当前本地用户与已验证 `QuestionPlan`；
2. 提供 `/practice/[sessionId]`：第一次回答、等待追问阶段、第二次回答和完成状态；
3. 第一次和第二次回答均以 `trim(text).length > 0` 为唯一文字门禁，保存为独立 `TrainingAnswer`；
4. 使用 `businessVersion`、幂等键和状态机拒绝陈旧/重复写入；第二次输入默认空白，绝不复制第一次；
5. 保存并恢复第一次与第二次的文字草稿 Checkpoint；
6. 实现用户主动请求的 H1—H5 `HintEvent`，提示内容只能来自已冻结问题支撑和个人资产版本；P07 展开准备材料不得自动记为提示；
7. 未接入 R6 时，为第一次回答后提供明确的“直接进入第二次回答”本地路径；
8. 补齐服务端、状态恢复、幂等与门禁测试，并更新验收记录。

## 禁止

- 最少词数、最少句数、隐藏字符数或“内容太短”提交阻断；
- 自动复制第一次回答到第二次回答；
- 在第二次回答前显示第一次正式 AI 评价；
- R6 随机追问、R7 正式评价、AI 失败清除用户输入；
- 用未批准资产、未确认事实或随机内容构造提示。

## 验收

- 单字符、标点或任意非空文字可保存；
- 同一幂等键的重复点击仅有一条 Answer；
- 会话版本失效或状态不匹配时安全拒绝且不写入；
- 刷新后恢复对应阶段与未提交草稿；
- 第二次回答默认空白，两个回答均可独立回读。
