把已完成的 F0—F7 实现收口为可在 Windows 本机运行、可在浏览器验证、可重复回归的 RC1 本地版本；不新增未经确认的产品能力。

## 范围

- 本地启动、停止、生产构建与运行说明；
- SQLite、目录、迁移、seed、冷启动和升级验证；
- 主要页面、设置导航、空状态和本地持久化实际验证；
- RC1 覆盖审计、发布门禁、用户验收与运维材料；
- 当前定稿范围内的启动、测试、设置或文案阻塞修复。

## 人工门禁

- 不调用真实 Provider；
- 不人工批准或激活 Bundle；
- 不创建 Git Tag、不推送远程仓库；
- 不覆盖或重置用户本地数据库。
