# Iteration 01｜应用骨架、应用壳与设置导航

## 目标

创建本地桌面 Web 工程骨架，并交付可运行的应用壳、一级导航和 P15 设置导航。只使用静态/模拟数据。

## 必做

1. 初始化 TypeScript Web 项目、Lint、格式化、Vitest、Playwright；
2. 实现固定左侧导航和 56px 顶部状态区；
3. 创建以下路由占位页：`/`、`/assets`、`/practice`、`/content`、`/graph`、`/history`、`/profile`、`/settings`；
4. 每个路由可点击、可刷新、显示当前选中状态；
5. P1/未实现页面显示明确空状态；
6. 设置页实现六个可点击分区和 hash/子路由深链；
7. 实验功能无内容时显示明确空状态；
8. 实现全局 AI 未配置、本地已保存和错误边界模拟状态；
9. 使用 DESIGN_SYSTEM Token，不自行换视觉方向；
10. 编写导航、设置和键盘操作 E2E。

## 禁止

- 不接数据库；
- 不接真实 AI；
- 不实现业务表单；
- 不加入录音、移动端、登录、支付、社区或公网能力；
- 不实现无文档支持的新组件系统。

## 验收用例

1. 从任一一级导航进入对应页面；
2. 浏览器刷新后仍在同一路由；
3. 键盘 Tab 可进入所有导航；
4. 设置六项点击后定位正确，URL 可复现；
5. “实验功能”显示空状态，不是灰色死按钮；
6. 1024px 可用，1280px 显示完整布局；
7. 页面无麦克风、录音、机器人、积分和移动底栏。

## 输出

`RESULT.md`：实现、测试、截图/走查、偏差和下一步建议。
