# F1-04｜个人资产、节点映射与连续段落

## 前置

F1-03 已实现经人工确认的只读来源资产版本及其来源证据链。

## 目标

从确认来源资产创建独立、可编辑后确认的个人资产版本，并在资产库与 P05 基础视图中以连续自然段呈现逻辑节点。

## 必做

1. 仅从确认来源资产创建个人资产草稿；个人资产和来源资产必须是独立版本，不得互相覆盖。
2. 保存个人节点到来源节点的 `PersonalNodeSourceMap`，并明确保留/改写等映射类型。
3. 创建 `PersonalAssetVersion`、节点与 `AssetFlowSpan`；服务端校验稳定文本范围、顺序及未声明重叠。
4. 提供资产库空态、列表和详情；详情使用连续自然段，不按节点或句子强制拆段。
5. 节点视觉颜色由 `NodeType` 设计映射派生，保留可访问文本语义，不保存颜色字段。
6. 明确显示来源版本链接、个人版本状态与“尚未进入多资产拼贴”的训练边界。

## 禁止

- 不修改来源资产版本或其证据；不自动创建个人资产；
- 不实现音频、AI 个人化、训练计划或拼贴训练；
- 不把颜色写入业务数据，也不以单句作为资产核心单位。

## 验收

- 来源与个人版本能相互追溯且相互独立；
- 非法或未声明重叠 Span 被拒绝；来源版本和个人确认版本均不能覆盖更新；
- 1024px 下资产详情可用；无个人资产时提供明确下一步；
- 通过 Vitest、Playwright、typecheck、lint、build 与 Prisma 校验。
