# F0｜工程、数据、导航与门禁基础

## 目标

建立可运行、可测试、可恢复的本地工程底座，不实现完整业务功能。

## 范围

1. 仓库与应用骨架；
2. 应用壳、一级导航、设置六分区；
3. Prisma Schema、迁移和 seed；
4. 本地文件/日志/备份目录；
5. P05/P08 门禁纯函数；
6. AI Provider/Task/Release Bundle 最小接口和 Mock；
7. Checkpoint、错误边界和测试；
8. F0 发布门禁。

## 非范围

真实文档解析、R1—R7、正式资产业务、正式训练评价、录音/语音、移动端、登录、支付、社区和公网部署。

## 验收

- 本地冷启动成功；
- 所有导航可点击；
- 设置六分区可深链且有内容/空状态；
- Prisma format/validate/迁移/seed 通过；
- P05/P08 门禁单测通过；
- 重复提交幂等基础通过；
- API 未配置仍可浏览与本地保存；
- Playwright F0 E2E 通过；
- RELEASE_GATE 中 F0 适用项全部 Pass。
