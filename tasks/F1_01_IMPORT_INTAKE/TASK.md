# F1-01｜安全导入接收与批次清单

## 前置

F0 Gate 已通过；`docs/04_DECISIONS.md` D-045 已定义导入安全默认限额。

## 目标

建立仅在本地运行的导入接收基础：课程集合、导入批次、文件清单、受控文件复制和可解释错误状态。此任务不解析文件内容，也不创建资产。

## 必做

1. 提供服务端 Import Intake Use Case 与 Repository 边界；UI 不直接导入 Prisma 类型。
2. 支持粘贴文本、单文件、多文件、文件夹和 ZIP 的输入描述；本轮只登记与安全复制，不进行 DOCX/PDF/TXT 内容解析。
3. 为每批导入创建 `SourceCollection`、`ImportBatch`、`ImportBatchFile`，保留原始文件名、类型、大小、Hash、来源路径和状态。
4. 原始文件只能复制到本地 `data/files` 的受控目录；所有路径经规范化，拒绝目录穿越。
5. 执行 D-045 限额：100 文件/批、25 MiB/文件、200 MiB/批、ZIP 100:1；配置可由环境变量覆盖。
6. ZIP 在本轮只完成受限检查与清单登记；禁止解压、禁止扫描内容、禁止 Zip Slip 风险写入。
7. 受限或不支持文件必须保留在文件清单中，并给出机器可读错误码与用户可读说明；同一批次的其他文件可继续登记。
8. 提供最小导入页或开发测试页，展示空态、已接收、部分失败和全部失败状态；不接入 AI。

## 禁止

- 不解析 DOCX/PDF/TXT，不做 OCR、网页抓取、音频解析或真实 AI；
- 不解压 ZIP，不创建 SourceDocument、SourceSegment、CandidateAsset 或任何正式资产；
- 不删除原始来源、不静默跳过失败文件、不写出 `data/files`；
- 不在浏览器、日志或数据库保存 API Key。

## 数据与迁移

- 先检查现有 Prisma 模型是否足够；若 Schema 与本任务冲突，停止并报告，不擅自改变产品模型；
- 若仅缺少迁移基线中已定义字段的 Repository/Use Case，直接实现；
- 本任务的测试使用独立 SQLite 文件，不污染默认本地数据库。

## 验收

- 合法粘贴文本和合法本地文件可创建批次及对应清单记录；
- 路径穿越、超单文件、超批次、超数量、ZIP 超压缩比和不支持类型均产生明确状态；
- 一个批次中合法与非法文件混合时，合法文件仍被登记，非法文件有可读原因；
- 原始文件 Hash 可复算，复制目标始终位于 `data/files`；
- Vitest 覆盖安全边界、Hash、部分失败、幂等与事务；Playwright 覆盖导入空态与状态展示；
- `pnpm run verify:f0` 保持通过，并在 `RESULT.md` 记录数据影响、错误状态和未实现解析边界。
