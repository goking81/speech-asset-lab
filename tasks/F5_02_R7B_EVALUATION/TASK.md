# F5-02｜R7B 六维评价、本地总分与部分结果

## 目标

在 F5-01 已保存的 AnswerUnit 和 R7A 资产调用证据基础上，生成六维评价草稿，并只由本地规则裁决可写入的维度结果、部分状态和总分；不进入 R7C/P09 复盘。

## 必做

1. 使用会话已冻结的 `AiReleaseBundle` 中 R7B Prompt；不得为旧会话补写、替换或混用 Bundle；
2. 为每个已保存回答建立幂等 R7B `AiTask`、Attempt、`AnswerEvaluationResult`、维度评分、问题归因、建议和修正草稿；
3. R7B 的“资产调用”维度只能读取 F5-01 的本地 R7A 当前结果，不能由模型重判或在 R7A 不可评价时伪造；
4. 评价和建议必须能引用 AnswerUnit、冻结资产节点、问题义务或明确本地规则；提示和追问不得写入六维原始评分；
5. 只在六维均为有效可裁决状态时，由本地按 `25/20/15/15/15/10` 写入正式总分；任一维不完整时保存明确的部分/不可评价状态且总分为空；
6. Provider 未配置/失败、输入不足、无 R7B Bundle、无效草稿时保留用户回答、R7A 结果和局部事实，绝不伪造评分、总分或掌握状态；
7. 增加所需 Prisma 迁移、服务/API/幂等和失败降级测试。首答评价仍不得在第二次回答前对用户展示；

## 禁止

- 让模型计算、写入或覆盖正式总分；
- 在 R7A 失败、部分或不可评价时伪造资产调用维度；
- AI 更新 `UserAssetState`、训练资格、阶段、正式资产关系或用户原始回答；
- 引入 R7C、P09 复盘、音频、实时语音或自动发布；
- 用词数、句数、关键词命中作为调用前阻断。

## 验收

- R7B 的每个可用维度、问题和建议均可回链到保存的证据或明确规则；
- R7A 的本地资产调用结论被锁定使用，模型无法覆盖；
- 六维全部有效时才有本地总分；任何缺失/失败时为可解释的部分结果且总分为空；
- 重复请求不重复创建当前结果、评分或建议；
- 失败路径不改变回答、资产状态、资格或阶段；
- P08 在第二次回答前仍不展示首答正式评价、分数或总分。
