# F7-01｜训练记录、备份恢复与日志隐私

## 目标

在不改变来源资产、个人资产、训练记录或冻结 AI Bundle 的前提下，完成本地训练历史回看、可校验备份与安全恢复，以及 AI 日志的保留和清理生命周期。

## 必做

1. 实现 P13 训练记录：可按资产、问题和状态筛选并回看完整会话、两次回答、主动提示、R7A/R7B/R7C 状态、降级来源与冻结 Bundle 版本；
2. 建立 `BackupRecord` 与本地备份服务。备份必须包含 SQLite、来源文件、必要设置和 Bundle 元数据，并保存版本、范围、状态、Hash、创建时间及恢复记录；
3. 恢复前校验备份格式、Hash、目标目录、可用空间和版本兼容性。恢复只能在本地允许的目录内进行，且覆盖前必须创建自动安全备份；
4. 恢复到隔离副本的验证与失败回滚必须可测试。任何校验失败不得修改当前 SQLite、来源文件或用户数据；
5. 在 P15 实现备份与恢复、AI 日志与隐私区块：显示安全相对/掩码路径、创建备份、备份列表、阻断恢复警告、原始响应保存开关、保留天数与日志清理操作；
6. 日志清理遵守用户配置，不保留完整 API Key、Authorization、密码、Secret 或 Token；清理日志不得影响正式资产、回答、训练记录或备份；
7. 增加迁移、路径边界、备份校验、隔离恢复、失败回滚、日志脱敏/清理和 P13/P15 端到端测试，并更新 RESULT.md。

## 禁止

- 跨目录恢复、接受绝对路径或目录穿越；
- 未创建安全备份就覆盖当前本地数据；
- 在浏览器、数据库普通字段、测试输出或日志中保存完整 Key；
- 因备份、恢复或日志清理而删除、覆盖或重新生成正式资产、用户回答、训练记录或历史 Bundle；
- 引入云备份、账号系统、支付、音频、实时语音或自动发布。

## 验收

- 训练记录可回看并显示真实状态、降级来源和冻结版本；
- 备份可被独立校验；隔离恢复成功且失败能回滚，当前数据保持可用；
- P15 恢复操作有阻断警告，路径只展示安全相对/掩码值；
- 日志配置与清理可验证，敏感值不会写入日志；
- 历史数据、正式资产、用户回答和冻结 Bundle 在所有失败路径保持不变。
