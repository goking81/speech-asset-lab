# CURRENT

当前任务：`UX-P08-01｜单题自主问题训练`

状态：IN PROGRESS

开始条件：用户反馈 P08 将多道问题拼成一题，保存第一次回答会同步等待 AI，固定“追问 1/3”和强制第二次回答无法说明训练目的，也让完整回答者被迫重复表达。

目标：把问题训练改为“一个问题、一条资产、用户自主决定下一步”的清晰流程。

范围：

- P06 将一行一道的候选问题拆成独立受支撑计划，并随机选择一题进入练习；开答前可换题，主资产保持不变；
- P07 明确本轮的可选动作和非强制边界；
- P08 首次保存只进行本地事务，移除同步 AI 等待；
- R6 仅在用户主动请求时给出一个可跳过、由冻结义务支撑的补充点；
- 用户可在第一次回答后直接完成，也可选择重新回答原题；双回答才进入可对照复盘；
- 更新产品规则、页面规格、测试、构建和发布验收记录。

完成条件：多个候选题不再连成一题；每次只练一道随机题且开答前可换；首次保存不触发 AI；不再显示“追问 1/3”；用户能直接结束或可选重答；自动测试、类型检查、静态检查、Prisma 校验、生产构建与视觉验收均有真实记录。
