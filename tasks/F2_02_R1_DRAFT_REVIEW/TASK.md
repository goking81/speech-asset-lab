# F2-02｜R1 提取草稿与人工审核

## 目标

为已解析来源内容建立 R1 候选草稿入口及证据校验；未配置真实 Provider 时明确停在安全降级，不生成或伪造候选。

## 必做

1. 仅以已解析、非重复来源段落为输入，并记录输入指纹与 Release Bundle。
2. Provider 未配置时创建可解释任务状态，不写入候选、不丢失来源内容。
3. 所有 R1 结果只能创建 `PENDING_REVIEW` 候选草稿和合法证据，不得自动确认来源资产。
4. 审核页显示草稿来源、Provider/降级状态及逐项人工操作。

## 禁止

- 不接入未经确认的真实 Provider；不自动发布；不编造无来源证据候选；不覆盖来源文本。
