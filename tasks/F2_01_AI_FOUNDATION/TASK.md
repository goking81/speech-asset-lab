# F2-01｜AI 发布包、Provider 配置与队列加固

## 目标

在不选择真实 Provider、不保存真实密钥的前提下，完成本地 Provider 配置、掩码显示、AI 任务持久化恢复与未配置安全降级。

## 必做

1. 设置页展示本地 AI Provider 配置状态、模型名、超时和重试；Key 仅显示掩码/引用。
2. 未配置 Provider 时，任何 AI 任务必须进入可解释的本地降级，不丢失用户数据。
3. 队列读取持久化 AiTask/AiTaskAttempt，支持安全恢复、重试上限、过期与 supersede。
4. Release Bundle、Prompt 定义和角色路由保持冻结；结果永远是草稿。
5. 完整 Key 不进入浏览器、数据库普通字段、日志或测试输出。

## 禁止

- 不自行选择、接入或调用真实 AI Provider；
- 不实现 R1 候选提取、R2/R3 编辑或自动发布；
- 不使 AI 失败阻断本地功能。

## 验收

- 未配置、超时、结构失败、重试用尽和 supersede 均可复现；
- 设置页明确未配置状态，无真实 Key 泄露；
- 用户数据先保存、AI 后处理的顺序不变；
- 全部工程门禁通过。
