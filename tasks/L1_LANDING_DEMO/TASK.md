# L1｜Landing Page Demo

## 目标

为 Speech Asset Lab 增加独立的 `/landing` 演示页面，让首次访问者快速理解语流资产、训练路径、当前试用版边界和进入工作台的入口。

## 验收

- 页面保持森林学习台的视觉语言，但不显示应用侧栏和运行状态条；
- CTA 可进入 `/` 与 `/assets`；
- 明确标注当前线上为“内置资产试用版”；
- 私有资料导入与 AI 整理只作为后续规划说明，不出现可执行入口；
- 不修改数据库、AI 调用、资产与训练门禁；
- 通过 TypeScript、lint 和 Landing 路由的浏览器验收。
