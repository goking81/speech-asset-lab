# 英语语流资产工作台｜桌面本地 MVP PRD

版本：0.5  
更新日期：2026-07-23  
产品形态：桌面优先、本地运行、单用户普通网页

## 1. 产品定位

帮助具备基础英语能力、但难以持续表达的学习者，将真实母语内容转化为个人语流资产，并通过复现、问题逆推、受约束调用和达到门槛后的拼贴训练，提高真实问题下的组织与连续输出能力。

## 2. 核心产品原则

1. **先有资产，再有挑战**：动态问题必须有已批准资产支撑。
2. **先稳定复现，再自由拼贴**：新人不直接进入多资产自由组合。
3. **AI 产出均为草稿或判断**：AI 不直接发布正式资产、关系、阶段或总分。
4. **来源可追溯**：原始来源只读保留，规范学习版记录 changeSet。
5. **个人版本优先训练**：正式训练使用个人资产版本。
6. **一次只增加一个主要难度变量**。
7. **图谱优先服务检索、调度和解释**。
8. **用户数据先保存，AI 后调用**。

## 3. 核心术语

- **语流资产**：可表达完整观点或经历、通常约 15—30 秒的连续语流；时长是默认训练目标，不是硬淘汰门槛。
- **来源资产**：从来源材料提取或重构的可追溯资产。
- **个人资产**：基于来源资产和用户确认信息形成的独立版本。
- **逻辑节点**：观点、原因、解释、例子、对比、行动、结果、结论等结构单位。
- **ExpressionUnit**：词伙、句式骨架、连接表达、词汇锚点；单个表达单元不等于完整资产调用。
- **锚点问题**：最直接调用一项资产的问题。
- **H0—H5**：主动提示阶梯；H0 无提示，H5 完整个人语流。
- **SourceCollection / ImportBatch / SourceDocument**：课程集合、一次导入批次、批次中的独立来源文档。

## 4. MVP 范围

### 4.1 包含

- 今日训练与本地 Coach 调度；
- 资产库、资产详情、来源/个人双版本；
- DOCX、TXT、文本型 PDF、粘贴文本、ZIP、文件夹和多文件导入；
- 本地安全解压、逐文件解析、重复提示和 AI 队列；
- 候选资产逐项审核；
- 个人资产生成和人工编辑；
- P05 熟读、关键词唤醒、逻辑骨架复现、无提示复现和锚点问题文字调用；
- P06—P09 受支撑问题、准备、第一次回答、0—3 轮追问、第二次回答和复盘；
- 训练记录、设置、本地备份与恢复；
- AI Provider Adapter、结构化校验、幂等、版本冻结和安全降级。

### 4.2 不包含

- 录音、麦克风权限、音频上传、转写、发音评分、停顿分析、实时语音；
- 移动端、微信小程序；
- 登录、多用户、权限、支付、社区；
- 扫描 PDF OCR、网页 URL 自动抓取；
- 正式公网部署；
- 完整全局图谱可视化。

## 5. 训练阶段

- S0—S1：资产积累期；
- S2：单资产调用期；
- S3—S5：拼贴期。

阶段、资产资格、拼贴解锁、任务优先级和状态更新由本地规则决定。

## 6. P05 资产训练产品规则

### 6.1 五步路径

1. **熟读理解**：显示个人语流的连续自然段。逻辑节点通过文字颜色和可访问语义标记区分，不显示数字，不把每句拆为独立段落。
2. **关键词唤醒**：用户看关键词或中文检索提示后口头复述；系统不录音。
3. **逻辑骨架复现**：显示中文逻辑骨架，用户口头复述；系统不录音。
4. **无提示复现**：不显示关键词、骨架、英文词伙或完整语流，用户口头复述；系统不录音。
5. **锚点问题调用**：用户可先口头回答，但页面只接收文字提交，AI 只评价提交文字。

遮挡复现和累积回忆是训练子任务，不改变五步核心路径，也不创建新的一级导航。

### 6.2 口头步骤记录

系统只记录用户自报：

- 完成情况：完整、基本、部分、未完成；
- 难度：轻松、合适、困难；
- 最高主动提示；
- 页面时长；
- 当前训练模式和资产版本。

不得根据停留时间推断“卡住”，不得声称识别遗漏、发音、语速或真实流利度。

### 6.3 门禁

口头步骤的“保存并继续”仅在以下条件全部满足时启用：

```text
oralAttemptConfirmed = true
completionRating != null
difficultyRating != null
saveStatus != SAVING
```

第 5 步提交仅要求：

```text
trim(answerText).length > 0
session is valid
submitStatus != SUBMITTING
```

禁止最少词数、最少句数和隐藏字符数限制。

## 7. P08 问题回答规则

- 第一次回答、追问回答和第二次回答均以非空文字为唯一输入门禁；
- 用户提交后先本地保存，再启动 R6/R7；
- “内容不足”可以是 AI 评价状态或降级结果，不得阻止用户提交；
- 第一次回答后 R6 与 R7A-1 可并行，但第一次评价不得在第二次回答前暴露；
- R6 失败允许直接进入第二次回答；
- 第二次回答默认空白，不复制第一次回答。

## 8. 设置页规则

设置至少包含可点击分区：

1. 训练目标；
2. AI 服务；
3. 本地数据与目录；
4. 备份与恢复；
5. AI 日志与隐私；
6. 实验功能。

每个分区必须有内容或明确空状态。P1/未开放内容不得表现为无响应控件。

## 9. 非功能需求

- 本地首屏目标 < 2 秒；普通本地增删改目标 < 500ms；
- AI 长任务不阻断全局导航；
- API Key 仅在本地服务端读取并掩码展示；
- 路径防穿越，ZIP 防 Zip Slip 和解压炸弹；
- 所有正式版本不可被 AI 原地覆盖；
- 重复点击和 Provider 重复回调必须幂等；
- 页面刷新和本地进程重启后可从 Checkpoint 恢复。

## 10. MVP 验收主链路

1. 导入课程包并逐文件处理；
2. 审核来源资产并保留证据；
3. 生成并确认个人资产；
4. 完成 P05 五步训练，口头步骤仅自报；
5. 输入受支撑问题并完成两次非空文字回答；
6. 展示 R7A/R7B/R7C 完整或安全降级结果；
7. 在训练记录中恢复和回看；
8. 在设置中完成 AI、本地目录、备份和日志操作。
