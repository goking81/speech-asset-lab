# 桌面本地 MVP 页面规格

版本：0.6  
更新日期：2026-07-23  
状态：P01—P11、P13、P15 为 P0；P12、P14 为 P1 或受限实现

## 0. 全局应用壳

左侧固定导航：今日训练、资产库、问题训练、内容工作台、关系图谱、训练记录、关于我、设置。顶部包含全局搜索、AI 任务、本地保存状态和导入内容。

所有可见导航必须满足：可点击、有目标页面、显示选中状态；未实现页面显示明确空状态，不允许点击无反应。

## P01 今日训练 `/`

显示当前阶段、可调用资产、今日时长、Coach 建议、今日任务、需要加强和最近改善。无资产时引导“导入内容 → 确认来源资产 → 生成个人版本 → 开始训练”。

## P02 资产库 `/assets`

一项列表记录代表一个完整资产对象，来源资产和个人资产不重复成两行。候选资产不进入正式资产库。

## P03 资产详情 `/assets/[id]`

来源版本只读，个人版本可编辑；展示节点、ExpressionUnit、问题关系、拼贴关系、训练历史和来源证据。

## P04 个人资产生成 `/assets/[id]/personalize`

两步：补充个人信息；检查并保存。AI 不得编造经历。确认后创建不可变个人资产版本。

## P05 资产训练 `/train/assets/[id]`

### 页面布局

- 左栏：资产、五步序列、完成标准；
- 中栏：当前练习；
- 右栏：主动提示与来源参考；
- 1024px 下右栏收为抽屉。

### 第 1 步｜熟读理解

- 显示个人核心语流或扩展语流的**连续自然段**；
- 不按句子拆段，不展示“01/02/03”等节点数字；
- 根据逻辑节点范围为原句文字着色；
- 页面提供小型图例或键盘/屏幕阅读器标签，颜色不作为唯一语义；
- 可打开来源对照，但不改变个人语流正文。

### 第 2 步｜关键词唤醒

- 展示中文检索提示、关键词或少量 ExpressionUnit；
- 用户进行口头练习；
- 系统不申请麦克风权限、不录音、不转写；
- 用户点击“我已完成口头尝试”后选择完成情况和难度。

### 第 3 步｜逻辑骨架复现

- 只显示中文逻辑骨架；
- 用户口头复现英文；
- 系统不录音；
- H1—H5 只能由用户主动展开，且记录最高提示。

### 第 4 步｜无提示复现

- 不显示关键词、逻辑骨架、英文词伙或完整语流；
- 只显示任务说明和计时；
- 用户口头复现，系统不录音；
- 默认 H0；若设计允许主动提示，提示展开后必须记录实际等级，不能继续记为无提示成功。

### 第 5 步｜锚点问题调用

- 显示锚点问题；
- 用户可先口头回答；
- 页面提供文字输入框；
- AI 只分析提交文字；
- 输入去除首尾空白后非空即可提交。

### P05 按钮门禁

| 控件 | 启用条件 | 禁止条件 |
|---|---|---|
| 我已完成口头尝试 | 页面非保存中 | 无需等待计时 |
| 保存并继续（第2—4步） | 已确认口头尝试 + 完成情况已选 + 难度已选 + 非保存中 | 缺任一自评、保存中 |
| 保存并继续（遮挡/累积回忆） | 与其口头/文字模式对应的必填项完成 | 不得使用隐藏门槛 |
| 提交文字（第5步） | `trim(text).length > 0` + 会话有效 + 非提交中 | 空白、无效会话、提交中 |

状态切换、输入和自评变化必须立即重新计算门禁；不得因 React 状态陈旧导致按钮持续灰色。

### P05 验收

- 连续段落中节点颜色范围准确且无数字；
- 第 2—4 步没有任何录音能力或录音暗示；
- 第 3 步有骨架，第 4 步无提示；
- 第 5 步才出现正式文字输入；
- 自评和难度选择后“保存并继续”可用；
- 刷新后可恢复当前步骤和未保存草稿；
- 每次尝试生成独立记录，不覆盖历史。

## P06 问题训练首页 `/practice`

输入真实问题或选择 Coach 推荐。新问题必须先进行可回答性检查；无可调用资产时不展示虚假推荐。

## P07 问题准备 `/practice/new`

展示问题、主资产、3—4 个中文回答节点和默认折叠的英文表达。展开准备材料不计正式提示等级。

## P08 问题回答 `/practice/[sessionId]`

### 流程

1. 第一次文字回答；
2. 0—3 轮受支撑追问；
3. 第二次重新回答原问题；
4. 进入 P09。

### 提交门禁

第一次回答、追问回答和第二次回答统一使用：

```text
canSubmit = trim(text).length > 0
            && sessionVersionIsCurrent
            && !isSubmitting
```

- 不设置最少词数、最少句数或隐藏字符数限制；
- 空白字符不算有效回答；
- 点击提交后先事务性保存，再启动 AI；
- AI 可能返回“文本不足以评价”，但页面仍保留回答并允许继续或重答；
- 重复点击不得创建重复回答。

### P08 验收

- 任意非空回答都能提交；
- 1 个单词也能保存，评价结果可标记不足但不能阻断；
- 网络/AI 失败不清除输入；
- R6 失败可直接进入第二次回答；
- 第二次回答默认空白。

## P09 复盘 `/practice/[sessionId]/review`

显示两次回答、总分、等级、六维、节点/义务变化、提示支持和 AI 解释。R7C 失败时使用本地 facts 和模板；R7B 失败时不得伪造六维。

## P10 内容导入 `/content/import`

支持单文件、多文件、文件夹、ZIP 和粘贴文本；显示文件清单、支持性、精确/近重复、跳过音频和逐文件队列状态。

## P11 候选审核 `/content/jobs/[jobId]`

逐项审核、编辑、确认修改或忽略；不支持一键确认全部。确认后只创建来源资产。

## P12 关系图谱 `/graph`

P1。P0 应显示明确空状态或“后续版本”说明；导航如保留必须可点击。

## P13 训练记录 `/history`

可回看完整会话、两次回答、提示、评价状态、降级来源和版本；支持按资产、问题和状态筛选。

## P14 关于我 `/profile`

P1，P0 可人工维护。若尚未实现 AI 画像，显示事实列表空状态和手动新增入口。

## P15 设置 `/settings`

### 导航

使用可点击页内锚点或子路由：

- `/settings#training` 训练目标；
- `/settings#ai` AI 服务；
- `/settings#storage` 本地数据与目录；
- `/settings#backup` 备份与恢复；
- `/settings#privacy` AI 日志与隐私；
- `/settings#experiments` 实验功能。

### 内容

1. **训练目标**：每日目标时长、活跃资产上限、每日新增目标；
2. **AI 服务**：Provider、Base URL、模型、Key 掩码、连接测试、超时、备用 Provider；
3. **本地数据与目录**：数据库、来源文件、日志和备份目录，只显示安全相对/掩码路径；
4. **备份与恢复**：创建备份、备份列表、恢复警告；
5. **AI 日志与隐私**：原始响应保存开关、保留天数、清除日志；
6. **实验功能**：无已批准实验时显示“当前版本暂无实验功能”，不提供假开关。

### P15 验收

- 所有导航项都能定位对应内容；
- 未实现内容显示明确空状态；
- API Key 不明文回显；
- 恢复操作有阻断警告；
- 不出现移动、语音、支付、社区或公网部署设置。
