# 已确认产品决策

版本：1.3
更新日期：2026-08-28

本文件继承 v0.6 的 D-001—D-037。以下新增决定具有同等效力。

## D-038 P05 连续原句与逻辑节点视觉

决定：P05 熟读理解中的个人语流使用连续自然段。逻辑节点通过不同文字颜色和可访问语义标记呈现，不显示数字、编号标签，不按节点或句子强制分段。

原因：用户需要在原句中直接看见逻辑链位置，同时保持自然语流和记忆整体性。

边界：颜色只做结构辅助，不作为业务状态；正式节点身份仍由 NodeType、节点 ID 和文本范围决定。

## D-039 P05 口头与文字练习边界

决定：P05 第 2—4 步为口头练习，系统不录音、不转写、不调用麦克风。第 3 步显示中文逻辑骨架，第 4 步无提示；第 5 步才输入文字，AI 只评价提交文字。

禁止：不得从页面时长推断口头表现，不得评价发音、语速、停顿或未提交内容。

## D-040 P05 自评与保存门禁

决定：第 2—4 步“保存并继续”必须在用户确认完成口头尝试、选择完成情况和选择难度后启用。状态变化必须即时重新计算；保存中防重复提交。

决定：自评是用户自报，不是 AI 评估；每次尝试独立保存，重练不得覆盖旧记录。

## D-041 P05/P08 非空文字提交

决定：P05 第 5 步及 P08 第一次、追问和第二次回答，只要去除首尾空白后非空即可提交，不设置隐藏词数、句数或字符数门槛。

边界：AI 可以在保存后返回 `INSUFFICIENT_TEXT` 或无法完整评价，但不得在提交前阻断；用户数据必须先保存。

## D-042 设置导航完整性

决定：设置页所有可见导航必须可点击并定位到真实内容。尚未实现或当前无配置项的分区显示明确空状态和版本说明，不允许保留点击无反应的入口。

## D-043 F0 开发交接门禁

决定：当前允许进入 Codex F0，只建立工程、数据、配置、导航、测试、恢复和发布门禁基础。Prisma 实机验证、应用启动、设置导航 E2E 和核心门禁单测通过前，不得进入 F1 业务开发。

## D-044 逻辑节点颜色派生

决定：逻辑节点颜色由 DESIGN_SYSTEM 对 NodeType 的映射派生，不在 SourceAssetVersion、PersonalAssetVersion 或节点记录中保存任意颜色值。文本范围通过稳定 offset/span 记录。

## D-045 F1 导入安全默认限额

决定：F1 导入入口采用本地可配置的默认限额：单批最多 100 个文件、单文件最多 25 MiB、单批累计最多 200 MiB、ZIP 单文件解压压缩比最多 100:1。

原因：在不引入云端处理的前提下，为文件夹、多文件和 ZIP 导入建立可测试的安全基线，降低 Zip Slip、解压炸弹和意外磁盘占用风险。

边界：这些是可由本地环境配置覆盖的工程默认值，不改变支持的文件类型或产品训练规则。超过限额的文件必须保留在 ImportBatchFile 清单中并显示明确失败/跳过原因；不得静默丢弃整个批次。

## D-046 F1 近重复候选默认规则

决定：F1 文本解析使用本地 token Jaccard 相似度识别近重复候选，默认阈值为 0.85。命中时只创建 `NEAR_DUPLICATE` 和待决重复关系，不自动合并、删除或替代来源文档。

边界：精确重复仍以规范文本 Hash 为准；近重复只是用户决策提示，不得阻止用户保留独立来源。

## D-047 R7B 六维评价与本地总分

决定：R7B 使用以下六个 0—100 分维度，按本地权重计算总分：资产调用 25%、问题义务覆盖 20%、问题相关性 15%、逻辑连贯性 15%、文字表达清晰度 15%、支撑细节充分度 10%。

边界：资产调用和问题义务覆盖维度只读取当前 R7A 的本地结果，不由 R7B 模型重判。模型只能产生其余四个维度的草稿及证据引用，不能计算或写入总分。只有六个维度均为有效可裁决状态时，本地才写入 0—100 的总分；任一维缺失、无效或不可评价时总分为空，并显示明确的部分/不可评价状态。

禁止：不得评价未提交的口头表现、发音、语速或停顿；提示与追问仅作为过程支持，不进入六维原始评分；不得以词数、句数或字符数阻断输入或直接写成零分。

## D-048 RC2 私有云端发布与数据边界

决定：在保留本地 RC1 交付物的前提下，启动 RC2 私有云端发布。线上运行使用 Cloudflare 承载应用、Supabase PostgreSQL 保存试用版业务数据；生产访问入口为 `speechasset.learnbox.cc`，并由 Cloudflare Access 限制为单一授权用户。来源原件和备份的私有 Storage 方案留待后续资料上传版本单独设计。

原因：用户已明确准备 GitHub、Cloudflare、Supabase 和 `learnbox.cc` 域名，需要从本机可运行版本迁移到可从个人设备安全访问的版本。

边界：这不是多用户 SaaS 化。仍保持单用户、桌面优先；来源资产保持可追溯和只读，个人资产独立可编辑；AI 产出仍永远是需要人工确认的草稿。GitHub 仅保存代码、公共静态资源和脱敏示例，不得提交学习资料、SQLite 数据库、备份、日志、API Key、数据库密码、Supabase service role key 或 Cloudflare token。

迁移约束：现有 SQLite migration 不能直接作为 PostgreSQL 的生产迁移执行，必须生成并评审独立的 PostgreSQL 基线。依赖本机文件系统、Python、Poppler、Tesseract 或 Windows OCR 的能力必须在上线前替换为兼容的受控服务；不得静默降级、丢失来源原件或将私有文件开放为公共 URL。

## D-049 RC2 内置资产试用版范围

决定：RC2 首次线上发布采用“内置资产试用版”。线上仅提供已筛选内置资产的浏览、五步训练、训练记录和受既有规则约束的 AI 草稿能力；不开放用户文件导入、PDF 解析、扫描件 OCR、来源原件上传或线上恢复操作。

原因：当前使用 Cloudflare 与 Supabase 免费额度，且试用目标是验证内置资产训练体验，而非构建个人资料上传服务。免费第三方 OCR 存在文件大小、页数、稳定性或第三方资料处理边界，不能作为正式默认能力。

边界：本机 RC1 的导入、PDF 解析与 OCR 代码和本地资料继续保留，不得删除或伪装为线上可用。线上导航和入口必须清楚标记试用版范围，不显示无法执行的导入操作。恢复导入前，必须单独完成私有 Storage、OCR 服务、文件大小限制与隐私审查。

## D-050 Landing Page Demo 边界

决定：根路径 `/` 用作对外 Landing Page，用于介绍“语流资产”的核心价值、来源资产到训练的路径，以及当前线上内置资产试用版的范围；学习工作台首页迁移至 `/lab`。旧的 `/landing` 链接自动回到根路径。Landing 的顶部导航在滚动时保持可访问，进入工作台在当前窗口内完成。它不改变现有训练规则。

边界：Landing Page 可以说明“私有资料导入与 AI 整理”为后续能力，但在完成私有 Storage、文件大小限制、OCR 服务与隐私审查前，不得显示可执行的线上上传入口，也不得表述为线上已可用功能。

## D-051 P05 提示递减与默写输出

决定：P05 五步训练固定为“看全文读顺 → 看词伙说出 → 看结构复述 → 无提示复现 → 默写输出”。左栏每一步必须同时表达“看什么”和“做什么”，并以“全文 → 词伙 → 结构 → 无提示 → 默写”说明提示逐步撤除。

决定：P05 训练页只呈现当前步骤所需材料。移除来源出处、来源对照、中文翻译/注释与 P05 内的锚点问题；来源可追溯性仍在资产详情保留，不在训练会话中干扰复现。第 2 步仅展示词伙，第 3 步仅展示中文逻辑结构，第 4 步与第 5 步均不得泄露英文原文、词伙或结构。

决定：第 5 步由“锚点问题调用”改为“默写输出”。用户在无提示条件下写下记得的英语表达；不要求逐字一致，不设置词数门槛，也不自动触发 AI 评价。默写用于巩固资产的逻辑与关键表达，问题调用继续由独立 P06—P09 问题训练承担。

兼容边界：历史数据层可继续使用既有 `ANCHOR_TEXT` 步骤枚举与 `textAnswer` 字段，避免迁移和旧记录失效；面向用户的名称、说明和行为统一为“默写输出”。

## D-052 P05 完成晋级与历史资格修复

决定：活动个人资产完成一轮完整 P05（`READING`、`KEYWORD_RECALL`、`LOGIC_SKELETON_RECALL`、`NO_HINT_RECALL`、`ANCHOR_TEXT` 五项均以 `COMPLETED` 保存）后，本地规则将其从仍处于 S0/S1 的早期状态晋级为 `S2 / SINGLE_ASSET_INVOCATION / CALLABLE`。当前会话在第 5 步“默写输出”保存成功时，于同一数据库事务内完成此晋级。

决定：为兼容此前已完整完成、但未写回资格状态的 P05 会话，P06 在读取可调用资产前按相同本地规则补算历史会话。补算只更新当前活动且仍在 S0/S1 的资产，不覆盖已处于 S2—S5 的后续阶段，也不复活已归档资产。

原因：P05 的完整训练证明用户已完成熟读与复现准备，其下一项训练就是 S2 的单资产调用（P06 问题训练）。此前只保存会话而未写回 `UserAssetState`，使已完成训练被错误拒绝，属于实现缺漏而非用户训练不足。

边界：晋级由五项已保存记录这一确定性本地规则裁决，AI 不参与、不评价口头过程；不伪造理解、调用或拼贴次数，不修改资产正文、来源数据或历史 Attempt。内部枚举继续仅用于存储，P13 必须显示用户术语而非 `ANCHOR_TEXT` 等枚举值。

## D-053 P08 单题自主练习

决定：P06 可将用户一次输入的多道问题拆成独立候选计划，并随机选一题进入本轮；用户在首次回答前可换题，所有候选题必须调用同一冻结主资产。P08 只围绕当前一道问题练习，页面清楚展示“本轮问题、调用资产和回答结构”。

决定：第一次回答保存只写入本地数据库并返回快照，不能同步调用 R6/R7 或等待 AI。保存后由用户自己选择直接结束、主动请求一个可跳过的单点补充，或另开空白回答框重新组织原题。补充不是评分、不是重复原题、不是固定轮次；R6 只在用户主动请求时运行，最多返回一项由冻结义务支撑的具体补充建议。

原因：一条资产对应多个可练习问题，但一轮练习应有明确焦点。把 AI 调用从保存路径移出，既避免网络延迟被误认为“保存卡死”，也不把额外表达变成完成训练的门槛。

边界：单次第一回答是完整有效的训练记录；只有用户主动保存第二次回答时才形成可对照的双回答复盘。不得显示“追问 1/3”、不得强制第二次回答、不得让 AI 评价或改写用户刚保存的文本。
