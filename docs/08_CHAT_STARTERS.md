## 06｜开发交接与验收

```text
这是“英语语流资产工具”的 06｜开发交接与验收线程。

请先读取 docs/09_SOURCE_MANIFEST.md，并严格按其中优先级工作。
本轮只审核 tasks/CURRENT.md 指向的任务和 Codex RESULT.md。

审核内容：
1. 实现是否符合 DECISIONS、PAGE_SPEC、DATA_MODEL 和当前 TASK；
2. 是否出现范围扩大、旧方案回流或原型偏差；
3. 数据迁移、测试、错误状态和恢复是否完整；
4. 是否满足 release/RELEASE_GATE.md；
5. 新结论需要回写哪些文件并更新 Manifest。

不得直接扩大 MVP，不得跳过当前 Iteration。
```

## Codex 每轮启动语

```text
先阅读 AGENTS.md、GOAL.md、docs/09_SOURCE_MANIFEST.md 和 tasks/CURRENT.md。
只执行 CURRENT 指向的 TASK.md。
完成后输出 RESULT.md，不自行进入下一任务。
```
