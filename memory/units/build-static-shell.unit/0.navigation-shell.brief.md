# Iteration 01 静态导航壳

## One-line memory

八个静态路由、设置 hash 深链接、桌面壳与自动化浏览器验收已完成，当前只等待审核。

## Why it matters

后续业务页应复用 `AppShell`、导航元数据和设计 Token，且不得将静态占位页误解为业务功能已上线。

## Core idea

- `src/lib/navigation.ts` 定义唯一的八个一级路由，`AppShell` 负责选中状态和键盘原生可达性。
- `src/lib/settings-navigation.ts` 定义六个设置分区；`/settings#experiments` 在刷新后可复现，并显示明确空状态。
- Vitest 有 2 项元数据测试；Playwright 有 4 项导航、键盘、hash 刷新和 1024px 覆盖。
- 1024px 的横向溢出已通过放松壳层最小列宽修复；`next.config.ts` 关闭开发工具浮层。
- 托管 Chromium 下载受网络阻塞，E2E 使用本机 Chrome；可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 覆盖路径。
