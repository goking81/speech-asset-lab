# Iteration 01 静态导航壳 — Full Memory

## Context

F0 审核确认后，按 `tasks/ITERATION_01/TASK.md` 实现桌面优先的静态应用壳。范围严格限定为路由、导航、状态模拟、设置深链接和错误边界，不进入数据库、真实 AI 或训练业务。

## Detailed notes

- 安装 `vitest` 与 `@playwright/test`，补齐 `test`、`test:run`、`test:e2e` 脚本。
- `primaryNavigation` 的路径顺序固定为 `/`、`/assets`、`/practice`、`/content`、`/graph`、`/history`、`/profile`、`/settings`。
- 设置分区 ID 固定为 `training`、`ai`、`storage`、`backup`、`privacy`、`experiments`。
- 页面使用 Slate / Blue-Green Token；所有未实现区域以明确空状态表达，避免假按钮。
- 浏览器走查发现 1024px 上 `html` 和网格最小宽度与垂直滚动条叠加造成横向滚动。最终将 `html` 最小宽度降至 960px，并将主工作区列改为 `minmax(0, 1fr)`；1024px 走查确认无横向溢出。
- Next 16 的开发工具按钮会显示为框架覆盖层；`next.config.ts` 已设 `devIndicators: false`。
- `pnpm exec playwright install chromium` 因网络下载长期无进度而停止。`playwright.config.ts` 使用本机 Chrome 的默认路径，且允许 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 覆盖。E2E 4 项均通过。
