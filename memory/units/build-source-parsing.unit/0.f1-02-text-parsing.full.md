# F1-02｜文本解析、Span 与重复（完整）

## 已确认实现

1. `TextParserService` 只读取已接收且 `READY` 的 `.txt` 文件。粘贴文本在 F1-01 中已被作为受控本地 TXT 保存，因而沿用同一解析路径。
2. 规范化只处理换行和首尾空白；以空行分段，顺序从 1 开始。每段保存 `textHash`，并创建 `PARAGRAPH` 注解，范围为 `0..segment.text.length`。
3. 精确重复先查 `parsedTextHash`；近重复仅在没有精确重复时比较来源段落组合文本。近重复阈值遵循 D-046，不改变用户的保留选择。
4. 启用格式只有 TXT。DOCX/PDF/ZIP 只更新到显式失败状态，不声称已经解析；不使用 OCR 或 AI。
5. 每个文件独立进入 `PARSING`。任何读取/解析异常仅将该文件置为 `PARSE_FAILED / LOCAL_FILE_READ_FAILED`，循环继续；最终批次按成功数量置为 `COMPLETED`、`PARTIAL_SUCCESS` 或 `FAILED`。
