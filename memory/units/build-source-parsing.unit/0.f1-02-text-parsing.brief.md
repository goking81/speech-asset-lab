# F1-02｜文本解析、Span 与重复（简要）

- `TextParserService` 仅解析本地 TXT / 粘贴文本，按稳定顺序写入 `SourceDocument`、`SourceSegment` 与完整段落 `PARAGRAPH` 注解。
- 文档与段落分别保存 SHA-256 Hash；精确重复使用规范文本 Hash，近重复使用 token Jaccard 0.85；两类关系都保持 `PENDING`，不会自动合并或删除。
- DOCX、PDF、ZIP 均未启用内容解析，明确为 `PARSE_FAILED / PARSER_NOT_ENABLED`；不进行 OCR、解压或 AI 修复。
- 单文件读取失败不会阻断同批其他文件，显示 `LOCAL_FILE_READ_FAILED` 并使批次进入 `PARTIAL_SUCCESS`。
- 内容工作台、导入和批次详情均为本地、无 AI 的可见入口。验证：37 项 Vitest、7 项 Playwright、typecheck、lint、生产构建和 Prisma 校验通过。
