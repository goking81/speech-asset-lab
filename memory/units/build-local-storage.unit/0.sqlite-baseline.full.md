# Iteration 02 SQLite 本地基线 — Full Memory

## Context

Iteration 02 将既有 Prisma Schema 落地为本地 SQLite 数据库，范围限定在迁移、最小 seed、目录与约束验证。

## Detailed notes

- 首迁移由 `prisma migrate diff --from-empty --to-schema-datamodel` 机械生成，随后追加两个版本不可变触发器。
- 当前 Windows/Prisma 6.19.3 环境不会自动创建 SQLite 文件；`scripts/setup-local-db.mjs` 先创建空文件后再执行 `migrate deploy` 与 seed。
- `prisma.config.ts` 在没有 `DATABASE_URL` 时提供默认值，同时不覆盖显式配置。
- `src/server/db/database-constraints.test.ts` 对全新临时数据库执行 migrate、seed 和约束验证；测试结束后清理其临时数据库。
- Prisma 会把 SQLite trigger 的 `RAISE(ABORT)` 映射为通用约束错误，因此不可变性测试断言写入拒绝且数据不变。

## Key excerpts / anchors

- 初始化脚本：`scripts/setup-local-db.mjs`
- Prisma 配置：`prisma.config.ts`
- 首迁移：`prisma/migrations/20260725090500_init/migration.sql`
- 约束测试：`src/server/db/database-constraints.test.ts`
- 本地路径：`src/server/storage/local-paths.ts`

## Implications

后续数据库写入不得直接从 UI 导入 Prisma 类型；确认版本的修改应创建新版本记录。文件写入必须先经过 `resolveLocalFilePath`。

## Open questions

- `migrate dev --create-only` 在当前环境无诊断信息，新增迁移前需先检查是否已恢复；
- Iteration 02 尚待审核，不得启动 Iteration 03。
