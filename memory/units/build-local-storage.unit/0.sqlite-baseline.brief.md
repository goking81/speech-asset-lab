# Iteration 02 SQLite 本地基线

## One-line memory

SQLite 首迁移、默认单用户 seed、本地目录适配器及数据库约束测试已经通过，等待审核。

## Why it matters

后续业务功能必须经由服务端边界访问本地数据库和文件目录，并保留当前迁移的版本不可变约束。

## Core idea

- `pnpm run db:setup` 可创建本地 SQLite 文件、data/files/logs/backups，应用迁移并执行 seed。
- `prisma.config.ts` 提供非敏感的默认 SQLite URL；用户显式 `DATABASE_URL` 优先。
- 首迁移包含 SourceAssetVersion 与 PersonalAssetVersion 的 SQLite 不可变触发器。
- 集成测试覆盖默认 seed、级联删除、不可变版本、AssetFlowSpan、尝试、答案和 AiTask 幂等约束。
- 本地路径适配器拒绝目录穿越，Repository 导出 UI 无关的类型。
