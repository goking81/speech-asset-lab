# RC1 Release Notes

建议版本：`0.1.0-rc.1`  
发布日期：待本地用户验收与人工发布门禁确认。

## 本次交付

- Windows 生产启动与安全停止入口：`start-local.bat`、`stop-local.bat`；
- SQLite、来源文件、日志、备份与隔离恢复的本地运行闭环；
- P01—P11、P13、P15 的本地页面与安全降级；P12/P14 按 P1 受限范围保留；
- P05/P08 门禁、R1—R7C 草稿链路、训练历史、备份、Golden Set、兼容记录和 Bundle 发布门禁；
- RC1 完整回归：25 个 Vitest 文件/99 项断言、21 项 Playwright、生产构建与冷启动。

## RC1 修复

- 新增可保存的本地训练目标设置，不改变阶段、资格或拼贴解锁裁决；
- 修正设置页中备份与 AI 区的过期文案；
- 新增 Windows 启动/停止安全记录机制与 UTF-8 兼容批处理；
- Playwright 改用隔离 SQLite/文件/日志/备份目录，且显式不配置真实 Provider；
- SQLite 集成测试改为串行文件执行，消除迁移竞争；
- 修复旧 R6-only Bundle 的降级回归及 P05 历史同时间戳排序。

## 不包含

公网部署、登录、多用户、移动端、音频/录音/转写/发音评分、支付、社区、自由 Prompt 编辑和图谱全局可视化。
