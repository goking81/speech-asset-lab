# RC1｜已知问题与边界

| 项目 | 状态 | 影响与处理 |
| --- | --- | --- |
| 真实 Provider 未由 RC1 自动调用 | 等待人工验证 | 用户需在设置页主动触发兼容检测；可能产生 API 费用 |
| 当前没有候选 Bundle | 等待人工验证 | 无法执行真实 Golden Set、人工批准或激活；本地安全降级仍可用 |
| R1—R7C 的真实语义质量 | 等待人工验证 | 自动化只验证结构、安全边界和降级；需人工审核合成 Golden Set 结果 |
| P12 关系图谱 | 不适用 | 规格定义为 P1，当前只提供明确空状态 |
| P14 AI 画像 | 部分 | 当前支持本地人工事实，不生成 AI 画像 |
| Windows 运行环境 | 用户前置条件 | 需要 Node.js 20.9+ 与 pnpm 11+；BAT 会明确提示缺失项 |

以上条目均不阻塞本地离线功能、自动化回归或 RC1 用户验收；前 3 项阻塞真实 AI 发布，不得以模拟结果替代。
